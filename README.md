# Robotics 300 Papers OA Downloader

Cloud downloader for the 300-paper DOM / Contact-rich / Assistive literature collection.

Only legally public/open-access PDFs are downloaded. No paywall bypassing.

## iPhone
Open **Actions → Download OA Papers → Run workflow**. Choose `DOM`, `Contact_Rich`, `Assistive`, or `all`. When the run finishes, download the ZIP artifact from the workflow run page.

The workflow also outputs `download_failures.csv` for papers for which no downloadable OA PDF was found.
